Keyboard shortcuts

Shortcuts save time, but you do not need to learn them all at once. Start with undo, brush size, and deselect. The rest will come naturally.

Text, paths, and dialogs

While typing text

  • Tool shortcuts stand down while the text field has focus, so you can type letters normally.
  • Press Place to commit the text.
  • Press Esc to cancel the text preview and restore the layer.

While editing path nodes

  • Drag anchors and handles with the mouse.
  • Click a segment to add a node.
  • Delete removes the selected node.
  • Esc or Enter leaves node editing.
  • Hold Alt while dragging a handle to break its symmetry.

While a modal editor is open

Modal editors include Layer Style, Colour Tools, Perspective, Mesh Warp, Smart Object, Image Size, Canvas Size, Shape, Text, and Batch. While one is open, tool shortcuts do not fire. Use the dialog buttons, or press Esc to cancel and close.
