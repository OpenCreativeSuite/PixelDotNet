Recipes

Short jobs with clear steps. Each recipe uses tools you already have and tells you where to read more. Start with the one closest to what you want to make.

Before any recipe Work on a copy. Use File → Save Project… before a big change, or duplicate the layer with Ctrl+J and hide the original. If something goes wrong, Ctrl+Z undoes the last step.

Remove something from a photo

Use when: a person, sign, wire, or litter is spoiling an otherwise good picture. Content-Aware Fill rebuilds the area from the pixels around it.

  1. Make a selection around the object. Press F for the Lasso and draw a loose outline, or press M for a rectangle. Leave a small ring of clean background around the object so the fill has something to sample.
  2. Fine-tune the edges. Hold Alt while drawing to subtract from the selection, or use the Add and Subtract buttons in the options bar.
  3. Choose Edit → Content-Aware Fill. The selected area is replaced with reconstructed texture and colour.
  4. Check the result at 100%. Press Ctrl+0, then Ctrl++ to zoom in. If it looks wrong, press Ctrl+Z and try a tighter selection.
  5. Blend if needed. A small amount of Healing Brush or Clone Stamp around the edge hides the join.
Best results Content-Aware Fill works best on small objects against fairly even backgrounds: a bird in the sky, a sign on a wall, a spot on sand. Very large selections or busy patterns may need several smaller passes.

Clean up a blemish or dust spot

Use when: a face has a spot, a scan has dust, or a clean surface has a small distraction. The Healing Brush copies texture and matches the surrounding tone, so repairs blend in.

  1. Duplicate the layer with Ctrl+J. Do repairs on the copy so the original is always available.
  2. Pick the Healing Brush with H. Choose a soft brush and a size just larger than the blemish.
  3. Set a source. Hold Ctrl and click a clean area near the blemish with similar colour.
  4. Paint over the blemish. Short strokes work better than one long smear. Set a fresh source whenever the texture starts to repeat.
  5. Use the Clone Stamp (C) when you need an exact copy of nearby texture instead of a blended repair.
Keep it subtle Repair at 100% zoom, then step back to normal size. A repair that looks invisible up close is usually invisible in the final picture too.

Cut a subject out of its background

Use when: you need a person or object on a transparent background for a poster, thumbnail, or another picture.

  1. Choose Quick Selection with A.
  2. Paint over the subject. The selection grows through connected, similar pixels. Start with a small brush on a clear edge.
  3. Take areas back. Hold Alt, or turn on Subtract in the options bar, and paint over background that was caught by mistake.
  4. Copy and paste the subject. Press Ctrl+C, then Ctrl+V. The selected pixels become a new layer.
  5. Hide the original layer. Click its eye in the Layers panel. The cut-out now sits on transparency.
  6. Refine the edge. Add a mask to the new layer, click the mask thumbnail, and paint black to hide stray background or white to bring areas back. Use a soft brush for hair and fur.
Why paste instead of masking straight away? Pasting gives you an independent cut-out immediately, while the original stays untouched below. The mask then becomes a gentle way to refine the edge rather than the only way to make the cut.

Add text to a picture

Use when: you need a title, a caption, a price, or a short message on an image.

  1. Press T for the Text tool.
  2. Turn on Text layer in the options bar if you may want to edit the words later. A text layer stays editable until you rasterize it.
  3. Click on the canvas where the text should start, then type in the field in the options bar.
  4. Choose the font, size, and alignment. Use B and I for bold and italic, and the alignment buttons to position the line.
  5. Add an outline or shadow. Click FX and choose a preset, or adjust the outline and shadow sliders yourself.
  6. Press Place to commit the text. To change it later, select the text layer and choose Layer → Edit Text….
Text on a busy background A thin white outline with a soft dark shadow lifts text off almost any photo. Both are in the FX panel.

Make text follow a curve

Use when: you are making a badge, a seal, a ribbon, or a title that should arc around artwork.

  1. Draw a path with the Pen (P). Click to place points along the curve. Drag while placing a point to pull out curved handles.
  2. Finish the path by clicking the first point or pressing Enter.
  3. Select the path layer in the Layers panel.
  4. Choose Layer → Text on Path…
  5. Type your text, then use Path offset to slide it along the path and Spacing to open the letters. Press Done.
  6. Restyle it. The result is a text layer, so you can change its font, size, colour, and FX like any other text.

The text stays linked to the path. If you edit the path nodes later with Layer → Edit Path Nodes, the text follows the new curve.

Turn a cut-out into a sticker

Use when: you want an image with a bold outline and a drop shadow, ready to drop onto another design.

  1. Cut out the subject using the recipe above.
  2. Select the cut-out layer.
  3. Open Layer → Layer Style… Or click the sparkle button on the layer row.
  4. Turn on Stroke, set the width to a chunky size, pick white, and turn Inside off for an outside outline.
  5. Turn on Drop Shadow, then lower the opacity, set a small distance, and add a little blur.
  6. Press Done, hide the original layer, and save a PNG so the transparent background is kept.
Why use a layer style? The outline and shadow are redrawn automatically if you paint on the layer or change its mask. You can also switch them off later without undoing your cut-out.

Make a black-and-white or duotone image

Use when: you want a timeless photo, a strong poster, or a two-colour look.

Black and white

  1. Select the layer you want to change.
  2. Choose Image → Desaturate or press Ctrl+Shift+U. Colour is removed while brightness stays.
  3. Add contrast. Open the Adjust tab and use the Contrast slider, or add a Curves adjustment layer.

Two-colour duotone

  1. Choose Image → Colour Tools….
  2. Scroll to Gradient Map. Set a dark colour and a light colour.
  3. Press Apply. Dark pixels take the dark colour; bright pixels take the light colour.

Resize and convert a folder of images

Use when: a folder of photos needs to be smaller for a website, or a set of PNGs needs to become JPEGs. No files are opened in tabs.

  1. Choose File → Batch Process….
  2. Set the Source folder that contains the images, then press Scan to count them.
  3. Set the Output folder. Use a separate folder the first time so you can check the results safely.
  4. Choose a Scale percentage. 100 keeps the original size; 50 makes each image half as wide and half as tall.
  5. Add a Suffix such as -web, and choose PNG, JPEG, BMP, or TGA.
  6. Press Run. The status line reports how many files were written.
Overwrite is off by default Leave it off until you have checked the output. When it is on, files with the same name are replaced.

Bring in an SVG logo

Use when: you have a logo or icon as an SVG and want to place it on a photo or design.

  1. Choose File → Import SVG…, or open the SVG through File → Open….
  2. Each shape becomes its own layer. Rectangles and ellipses stay editable shapes; rotated artwork becomes editable paths; text becomes a text layer.
  3. Move and scale the layers with the Move tool, or edit a shape from Layer → Edit Shape….
  4. Recolour it by selecting a shape layer and choosing a new fill colour in the shape editor, or use the Adjust tab.
  5. Export it again with File → Export SVG… if the design should stay vector.

Start a painting from a blank canvas

Use when: you want to draw or paint something new rather than edit a photo.

  1. Choose File → New Document (Ctrl+N) for a 768 by 576 canvas. Use New Small Document for a 480 by 360 test canvas.
  2. Sketch on a layer. Press B, pick a dark colour, and block in the main shapes. Keep the sketch loose.
  3. Lower the sketch opacity in the Layers panel, then add a new layer above it for colour. The sketch shows through the gaps while you block in colour.
  4. Paint the colour. Use a large soft brush for backgrounds and a smaller hard brush for details. Lower Opacity to build colour gradually.
  5. Add clean line art or text on a layer above the colour. For a crisp line, turn on Shape layer with the Pen tool.
  6. Save a project with File → Save Project… so the layers survive, then save a PNG for sharing.
Three layers are enough to start Background, colour, and line art. Add more only when a new kind of work needs its own space.
